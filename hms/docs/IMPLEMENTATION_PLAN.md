# Implementation plan

Each phase ends with a running, tested system. High-risk features are not marked done without tests.

| Phase    | Scope                                                                                                                                                                                                                                                                                                                                                                                                     | Exit criteria                                                                                                       |
| -------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------- |
| **1 ✅** | Foundation: schema/migrations, auth (Argon2id, DB sessions, lockout, TOTP MFA, reset), RBAC with branch scope + two-person role changes, hash-chained audit, settings & setup checklist, branches/departments/wards/beds/visit types, staff accounts, patient registry (duplicates, merge, identifiers, allergies, consents, guardians), appointments, check-in, queue, dashboards, break-glass, UI shell | Registration → appointment → check-in → queue works in browser; unit/integration/E2E green                          |
| 2        | Encounter workspace, SOAP notes with signatures & addenda, vitals/triage with units, diagnoses, orders, lab (specimen → result → verification → release, critical acknowledgement), imaging reports, document storage adapter, clinician/nurse worklists                                                                                                                                                  | Visit → lab order → verified result → clinician review E2E; signed notes immutable; verified results only amendable |
| 3        | Prescribing, pharmacist verification, FEFO lot dispensing, stock ledger, suppliers, requisition → PO → GRN, transfers, counts, expiry/low-stock alerts                                                                                                                                                                                                                                                    | Dispense once updates treatment record, stock and (if configured) billing exactly once; expired lots blocked        |
| 4        | Service catalogue with effective-dated tariffs, invoices, payments (idempotent), deposits, refunds, cashier shifts, HMO partners/plans/tariffs, coverage decisions, pre-auth, claims, batches/export, remittance reconciliation, ledger                                                                                                                                                                   | HMO patient → covered service → manual auth → claim → partial remittance reconciled                                 |
| 5        | Pregnancy episodes, ANC with trends, dating events, labour/delivery, newborn records (multiples), postnatal; admissions with atomic bed allocation, transfers, discharge & financial clearance                                                                                                                                                                                                            | ANC → delivery → mother/newborn discharge; concurrent bed assignment yields one winner                              |
| 6        | HR/rosters/leave/payroll (configurable, reviewed rules), patient/guardian portal, notification adapters, reports/exports with watermarking, FHIR mapping, accessibility & mobile pass, threat model, DPIA prep, backup/restore dry run                                                                                                                                                                    | Security review, restore test, go-live checklist ready for sign-off                                                 |

Work proceeds without waiting for approval on routine engineering choices; anything requiring
hospital policy, clinical sign-off or credentials stays configurable and disabled.
